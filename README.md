# VibeTV

Releases of **VibeTV Manager** for macOS: the Mac app that runs your own AIOStreams server
at home, with private access over Tailscale.

Download the latest disk image from [Releases](https://github.com/michaellzc/vibetv/releases/latest),
open it, and drag VibeTV Manager into Applications. The app keeps itself up to date from here.

This repository holds release files only (disk images, the update feed and runtime packs).
